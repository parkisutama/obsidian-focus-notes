# Dokumentasi user

Mulailah dari hasil yang ingin Anda capai. Dokumentasi user tidak disusun berdasarkan nama modul atau struktur kode, tetapi berdasarkan pekerjaan nyata di Obsidian.

## Tutorial

Tutorial memandu Anda dari awal sampai mendapatkan hasil. Ikuti langkahnya secara berurutan ketika pertama kali mempelajari sebuah alur.

- [Jalankan sesi fokus pertama](tutorials/first-focus-session.md)

## How-to

How-to membantu menyelesaikan satu kebutuhan spesifik. Gunakan setelah Anda memahami dasar penggunaan plugin.

- [Tangkap ide atau konteks dengan cepat ke Inbox](how-to/capture-to-inbox.md)

## Ketika Anda perlu memahami lebih dalam

Panduan user dapat mengarah ke dokumentasi developer ketika keputusan teknis memengaruhi hasil yang terlihat, misalnya format Markdown, resolusi target note, persistence, atau kompatibilitas Obsidian. Anda tidak harus membaca bagian developer untuk menggunakan plugin.
