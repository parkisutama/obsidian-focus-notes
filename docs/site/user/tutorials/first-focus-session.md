# Jalankan sesi fokus pertama

Tutorial ini membawa Anda dari membuka Focus Notes sampai menyimpan satu catatan sesi fokus ke vault.

## Hasil akhir

Setelah selesai, Anda akan memiliki satu entri sesi yang mencatat waktu fokus dan konteks pekerjaan di note tujuan.

## 1. Buka panel Focus Notes

Buka Command palette di Obsidian, lalu jalankan **Open Focus Notes panel**. Anda juga dapat memakai ikon timer di ribbon.

## 2. Pilih mode

Gunakan salah satu mode berikut:

- **Pomodoro** untuk sesi hitung mundur dengan durasi fokus default.
- **Timer** untuk hitung mundur dengan durasi yang Anda tentukan.
- **Stopwatch** untuk sesi tanpa batas waktu awal.

Untuk tutorial pertama, pilih **Pomodoro**.

## 3. Tulis fokus Anda

Isi focus input dengan hasil yang ingin dikerjakan, misalnya `Tinjau rancangan Inbox`.

## 4. Mulai dan selesaikan sesi

Tekan tombol mulai. Ketika pekerjaan selesai, pilih **Stop & Log**. Anda tidak perlu melanjutkan timer terlebih dahulu jika sesi sedang dijeda.

## 5. Lengkapi catatan

Di modal pencatatan:

1. Periksa judul atau aktivitas.
2. Pilih tingkat stres dan emosi jika ingin mencatat wellbeing.
3. Tambahkan refleksi atau hasil kerja.
4. Tambahkan related note bila relevan.
5. Simpan.

## 6. Periksa hasil di note tujuan

Buka note tujuan yang terlihat pada panel. Entri sesi ditulis mengikuti target dan template aktif di Settings.

## Langkah berikutnya

- Gunakan [Inbox quick capture](../how-to/capture-to-inbox.md) ketika Anda perlu menangkap konteks tanpa memulai timer.
- Lihat [peta fitur untuk developer](../../developer/reference/feature-map.md#timer-dan-session-logging) untuk mengetahui komponen yang membentuk alur ini.
