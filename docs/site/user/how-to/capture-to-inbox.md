# Tangkap ide atau konteks dengan cepat ke Inbox

Gunakan Inbox ketika Anda ingin mencatat sesuatu sekarang dan mengorganisasikannya nanti.

## Buka form capture

Jalankan command **Create event or task**. Form terbuka dengan **Inbox** sebagai pilihan awal.

## Tulis capture

- Pertahankan timestamp sebagai judul jika kecepatan lebih penting daripada penamaan.
- Ganti judul jika konteks singkat sudah jelas.
- Tulis detail pada Notes.
- Ketik `@` untuk memilih People atau Place dari sumber suggestion yang dikonfigurasi.
- Ketik `#` untuk memilih tag vault.

Pilihan `@` berubah menjadi link Markdown relatif terhadap note tujuan. Karakter `@` hanya berfungsi sebagai trigger dan tidak ikut disimpan sebagai bagian link.

## Pilih tujuan bila diperlukan

Buka bagian **More options** untuk mengganti target file, heading Inbox, posisi insertion, atau sumber folder suggestion pada capture tersebut.

Secara default capture mengikuti note Markdown yang sedang aktif sehingga Inbox, Event, dan Task dapat dicatat langsung pada hub atau Project Note. Di Settings, Anda tetap dapat memilih Daily Note agar Inbox selalu ditulis di bawah heading Inbox harian.

## Simpan

Pilih **Save**, lalu periksa bullet baru di bawah heading tujuan. Jika target tidak dapat diselesaikan, form tidak boleh diam-diam menulis ke file fallback.

## Referensi implementasi

Lihat [Inbox quick capture pada peta fitur](../../developer/reference/feature-map.md#inbox-quick-capture) untuk kontrak target, suggestion, dan output Markdown yang mendasari alur ini.
