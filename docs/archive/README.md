# Archived Planning Documents

Folder ini berisi plan, todo, dan spec yang sudah dipakai untuk implementasi.
Dokumen tidak dihapus agar konteks keputusan dan urutan perubahan tetap tersedia.

Untuk referensi aktif, mulai dari [Current State](../current-state.md),
[Usage Workflow](../usage-workflow.md), dan [Changelog](../changelog.md).

## Isi arsip

- `tasks/` — rencana dan checklist implementasi yang sudah selesai.
- `specs/` — kontrak dan requirement yang sudah diwujudkan dalam code.

Dokumen arsip adalah historical record. Perubahan baru harus memperbarui
dokumentasi aktif dan, bila menyangkut keputusan yang sulit dibalik, menambah ADR.
